# Cybersecurity Labs

This repository documents my hands-on cybersecurity learning through labs, CTF challenges, experiments, and technical notes.

I'm an Information Security student at United Arab Emirates University (UAEU), and I'm using this repository to move beyond learning concepts theoretically and practice applying them in real environments.

## Goals

- Build stronger cybersecurity fundamentals
- Practice concepts through hands-on labs
- Develop CTF problem-solving skills
- Learn security tools by actually using them
- Document mistakes and lessons learned
- Improve my technical reasoning
- Build a personal security knowledge base

## Learning Areas

### Linux
Linux fundamentals, permissions, processes, services, command-line tools, and security-related system administration.

### Networking
TCP/IP, ports, protocols, DNS, HTTP/HTTPS, packet analysis, Wireshark, and network-security fundamentals.

### Web Security
HTTP, authentication, sessions, browser security, common web vulnerabilities, and authorized web-security labs.

### Cryptography
Encoding, hashing, encryption, XOR, classical ciphers, and cryptography challenges.

### Digital Forensics
File analysis, metadata, file signatures, logs, packet captures, and forensic investigation techniques.

### OSINT
Public-information gathering, verification, research techniques, and OSINT challenges.

### Scripting
Python and other small scripts created to automate repetitive cybersecurity tasks or help solve challenges.

### CTF Write-ups
Notes and write-ups from CTF challenges where public solutions are permitted.

## Lab Note Structure

For most labs, I will document:

1. **Objective** — What was I trying to accomplish?
2. **Concepts** — What security concepts were involved?
3. **Approach** — How did I approach the problem?
4. **What Didn't Work** — What mistakes or failed approaches did I encounter?
5. **Solution / Result** — What ultimately worked?
6. **What I Learned** — What did the lab actually teach me?
7. **Defense Perspective** — How could the issue be prevented, detected, or mitigated?
